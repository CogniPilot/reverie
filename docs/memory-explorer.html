What enters the agent's short-term context?

The CTO chooses a task, retrieves scoped candidates, checks evidence and selects complete records that fit. This demo uses a hand-curated relevance order and a UTF-8 byte budget, not a production tokenizer or retrieval benchmark.

Storage and organization

One stable record, many views. Store records, tags, source references and typed links in SQLite. Add a full-text index for exact names/errors; add semantic search when measurements justify it. A generated tree groups records by tags without changing IDs, evidence or permissions.

Self-organization. Agents suggest tags on write. During consolidation, the CTO can merge synonyms, split crowded branches, revise summaries and add associations. Keep the original record and the reason for factual revisions. Contradictions remain visible until resolved. Tree placement is an index, not evidence.

Private memory is a separate store. Scope is enforced before retrieval. Tags cannot publish an agent's private experiences. Shared records are concise, reviewed project knowledge; raw DMs, transient dreams and bulk tool logs do not belong here.

Retention. Keep useful episodes and verified lessons, compact repetitive handoffs, and retain stable source/test receipts. Relevance may fade; project evidence is not erased merely because it was seldom recalled. Dream hypotheses stay unverified until tested.

Human-inspired is a design analogy, not a claim of biological equivalence. Scientific inspirations: complementary learning systems, memory systems. Retrieval: contextual/hybrid retrieval, LongMemEval. Reverie is a fork of Codeman.
