# Installed Nix store bootstrap

`reverie-nix-store-prepare` is the fixed guest entry point for an unprivileged,
networkless worker preparation container. It accepts no paths or engine argv.
Host `worker_nix::guest` owns the actual registration stream, child processes,
database freeze and image GC root. The CLI contains argument help, the original
five-minute outer budget, checked shutdown and bounded post-settlement output.

The installing broker still owns image admission, actual storage resources and
the container lifecycle. This binary does not grant a laptop start, prove all
writers stopped, or authorize use of a host Nix daemon. Package/source selection
requires the complete host preparation workflow qualification.
